# Rahul Teja - Portfolio

Personal portfolio showcasing AI engineering, autonomous agent systems, full-stack architectures and production projects.

## 🌐 Live Website
[https://www.nrahulteja.me/](https://www.nrahulteja.me/)

## 🚀 Tech Stack
- **Framework**: Next.js 14 (App Router)
- **UI / Styling**: React 18, Tailwind CSS, Framer Motion
- **3D Graphics**: Three.js, GLTFLoader
- **Language**: TypeScript

## 🛠️ Local Development
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## 📦 Production Build
```bash
npm run build
npm run start
```
